#  Spring Boot Actuator

Spring Boot Actuator provides **production-ready features** to help monitor and manage your applications.  
It exposes a set of **built-in endpoints** for health checks, metrics, environment details, and more.

---

## 1. Installation

Add the dependency in `pom.xml`:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
```

---

## 2. Access

Default base path:

```
http://localhost:8080/actuator
```

---

## 3. Common Endpoints

|Endpoint|Description|
|---|---|
|`/actuator/health`|Shows application health status (UP/DOWN)|
|`/actuator/info`|Displays application info (customizable in `application.properties`)|
|`/actuator/beans`|Lists all Spring beans in the application context|
|`/actuator/env`|Shows Spring Environment properties|
|`/actuator/mappings`|Displays all request mappings (`@RequestMapping`, `@GetMapping`, etc.)|
|`/actuator/threaddump`|Shows JVM thread dump|
|`/actuator/metrics`|Exposes metrics (CPU, memory, GC, HTTP request counts, etc.)|

---

## 4. Configuration

### Change Base Path

```properties
management.endpoints.web.base-path=/management
```

### Expose Specific Endpoints

```properties
management.endpoints.web.exposure.include=health,info,beans,env
```

### Expose All Endpoints (not recommended in prod)

```properties
management.endpoints.web.exposure.include=*
```

---

## 5. Customize `info` Endpoint

`application.properties`

```properties
info.app.name=Patient Management System
info.app.version=1.0.0
info.app.author=Adarsh Pandey
info.app.documentation=http://documentation.com
```

Access at:

```
http://localhost:8080/actuator/info
```

---

## 6. Example: `health` Output

```json
{
  "status": "UP"
}
```

Can be extended to include DB, DiskSpace, Redis checks, etc.

---

## 7. Important Notes

- **Security:** By default, only `/health` and `/info` are exposed. Other endpoints require explicit exposure.
    
- **Production Best Practice:** Secure actuator endpoints using **Spring Security**.
    
- **Thread Dump:** Useful for debugging deadlocks & stuck threads; generates a detailed report of JVM threads.
    
- **Heap Dump (different):** Requires enabling `/heapdump` endpoint; gives full JVM heap snapshot for memory analysis.
