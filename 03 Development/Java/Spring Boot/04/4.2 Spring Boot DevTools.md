
# Spring Boot DevTools

- Normally, whenever we make changes in code, we have to restart the application manually.  
- With **Spring Boot DevTools**, the application automatically restarts whenever code or resources are updated.

---

## 1. Add Dependency

```xml
<!-- https://mvnrepository.com/artifact/org.springframework.boot/spring-boot-devtools -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <version>4.0.0-M1</version>
</dependency>
```

---

## 2. Enable Auto-Build in IntelliJ IDEA

- **Step 1:** Press `Ctrl + ,` → Go to **Build, Execution, Deployment → Compiler** → Tick ✅ _Build project automatically_.
    
- **Step 2:** Go to **Advanced Settings** → Tick ✅ _Allow auto-make to start even if the application is running_.
    

---

## 3. Automatic Restart

- DevTools **automatically restarts** the application whenever classpath files change.
    
- Restart is **faster than a full restart** because it uses **two classloaders**:
    
    - **Base classloader** → for stable classes (e.g., libraries).
        
    - **Restart classloader** → for application classes (that change).
        
- When a change is detected, **only the restart classloader is refreshed**.
    

---

## 4. Configuration Options (application.properties)

```properties
# Disable automatic restart
spring.devtools.restart.enabled=false

# Exclude specific paths from triggering a restart
spring.devtools.restart.exclude=static/**,public/**

# Polling interval (ms) to check for changes
spring.devtools.restart.poll-interval=2000

# Quiet period (ms) before triggering restart
spring.devtools.restart.quiet-period=1000
```

---

⚡ This keeps restarts **lightweight, efficient, and developer-friendly**.
