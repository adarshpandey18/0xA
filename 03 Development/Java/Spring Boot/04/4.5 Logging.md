# Logging
- Logging is the process of tracking all the events that happen after a piece of code is run.
- It is every important aspect of software development as it helps to track where exactly the code crashes and this eases debugging.
- A logging framework can be used to perform all the tasks like setting log file destinations, customizing log messages, etc.

## SLF4J (simple logging fasad)
to make logging easier for programmer. java provides a variety of loggin framework like log4j, java.util.loggin (jul) tiny log logback etc.

spring boot comes with slf4j inbuilt which is abstraction of all the loggin framework slf4k stands for simple logging facade for java.
it allows user to work with any of the loggin framework with a single dependency.

## Elements of Logging Framework
Every logging framework comes with three elements.
1. Logger = capture the messages.
2. Formatter = formats the messages captured by the logger.
3. Handler = Dispatches the messages by printing them on the console or storing them in a file sending an email etc.
## Log Levels
The messages logged can be of various security levels. Spring boot supports five log levels which are
1. FATAL - fatal error crashing the system
2. ERROR - runtime error
3. WARN - warning
4. INFO - events occuring at the run time
5. DEBUG - information about the flow fo the system.
6. TRACE - more detailed information about the flow of the system.

```java
log.error("error log");
log.fatal("fatal log");
log.info("info log");
log.warn("warn log");
log.trace("trace log");
log.debug("debug log");
```

they are just the marker they don't mean anything
