#  Core Spring Security Components

## 1. **UserDetails**

- **What it is**:  
    A contract that represents the _authenticated user_ inside Spring Security.
    
- **Purpose**: Encapsulates username, password, roles, and account status flags (locked, expired, etc.).
    
- **Key Methods**:
    
    - `getUsername()`
        
    - `getPassword()`
        
    - `getAuthorities()` → returns roles/permissions
        
    - `isAccountNonExpired()`
        
    - `isAccountNonLocked()`
        
    - `isCredentialsNonExpired()`
        
    - `isEnabled()`
        

 >Best Practice: Extend `UserDetails` in your **User entity** so DB + Security stay in sync.

---

## 2. **UserDetailsService**

- **What it is**:  
    A service interface with a single method:
    
    ```java
    UserDetails loadUserByUsername(String username);
    ```
    
- **Purpose**: Fetch user details (username, password, roles) from a **data source** (DB, LDAP, etc.) for authentication.
    
- **Custom Implementation**: Usually you implement this using your `UserRepository`.
    

 > Note: Spring Security uses this under the hood in **DaoAuthenticationProvider** during authentication.

---

## 3. **InMemoryUserDetailsManager**

- **What it is**:  
    An **in-memory** implementation of `UserDetailsService`.
    
- **Purpose**:
    
    - Quick prototyping
        
    - Unit tests
        
- **Example**:
    
    ```java
    @Bean
    public UserDetailsService userDetailsService(PasswordEncoder encoder) {
        UserDetails user = User.builder()
                .username("adarsh")
                .password(encoder.encode("password"))
                .roles("USER")
                .build();
        return new InMemoryUserDetailsManager(user);
    }
    ```
    

> Not recommended for production apps.

---

## 4. **PasswordEncoder**

- **What it is**:  
    A strategy interface for hashing + verifying passwords.
    
- **Purpose**: Never store plaintext passwords, always **hash + salt** them.
    
- **Common Implementations**:
    
    - `BCryptPasswordEncoder` (default, recommended)
        
    - `Pbkdf2PasswordEncoder`
        
    - `SCryptPasswordEncoder`
        
    - `Argon2PasswordEncoder`
        

> Best Practice: Always inject it as a `@Bean`.

```java
@Bean
public PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder();
}
```

---

## 5. **AuthenticationManager**

- **What it is**:  
    The central strategy interface that processes authentication requests.
    
- **How it works**:
    
    - Delegates to one or more `AuthenticationProvider`s (like `DaoAuthenticationProvider`).
        
    - Returns an `Authentication` object if successful.
        

> Typically injected in login flows to authenticate credentials.

---

## 6. **AuthenticationProvider**

- **What it is**:  
    Validates credentials for a specific authentication type.
    
- **Common Example**: `DaoAuthenticationProvider` (uses `UserDetailsService + PasswordEncoder`).
    
- **Custom Providers**: Can be built for JWT, OAuth2, API Keys, etc.
    

---

## 7. **GrantedAuthority**

- **What it is**:  
    Represents a permission/role.
    
- **Example**: `"ROLE_ADMIN"`, `"READ_PRIVILEGE"`.
    
- **Purpose**: Used for authorization checks like:
    
    ```java
    @PreAuthorize("hasRole('ADMIN')")
    ```
    

---

## 8. **SecurityContext & SecurityContextHolder**

- **What it is**:  
    Holds the current `Authentication` (user principal + authorities) for the request.
    
- **Lifecycle**:
    
    - Populated once the user is authenticated.
        
    - Available throughout the request.
        
- **Access Example**:
    
    ```java
    Authentication auth = SecurityContextHolder.getContext().getAuthentication();
    String username = auth.getName();
    ```
    

---

 With these, you now cover **the full set of Spring Security building blocks**:

- **Identity Representation** → `UserDetails`
    
- **User Lookup** → `UserDetailsService`
    
- **Authentication Engine** → `AuthenticationManager` + `AuthenticationProvider`
    
- **Password Safety** → `PasswordEncoder`
    
- **Authorization** → `GrantedAuthority`
    
- **Context** → `SecurityContext`
