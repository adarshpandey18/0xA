# Configuring SecurityFilterChain


by configuring security filter chain we can add more filters or remove filters.
to customize according to our needs and don't want to work with default securityfilderchain

```java
@Configuration
@EnableSecurity // telling spring boot that now we want to configure securityFilterchain
public class WebSecurityConfig {
	
	@Bean
	SecurityFilterchain securityFilterChain(HttpSecurity httpSecurity) throws Exception {
		return httpSecurity // can do lot of things 
			.formLoging(formLoginConfig -> formLogConifg.loginPage("/index.html")
			
			) // if we don't config it now it wont work so now its necessary to implement certain things 
			// to authorize request
			.authorizeHttpRequest(auth -> auth
			.anyRequest().authenticated()
			)
	}

}
```
