# RestClient

- **RestClient** is a **synchronous HTTP client** introduced in Spring 6 (and Spring Boot 3).
    
- It provides a **modern, fluent API** for making REST calls.
    
- It acts as an **abstraction over HTTP libraries**, simplifying:
    
    - Conversion of Java objects to HTTP requests
        
    - Parsing HTTP responses into Java objects
---
## Blocking vs Non-Blocking

- **Blocking (Synchronous)**
    
    - The thread making the HTTP request **waits** until the response is received.
        
    - Simple to use and reason about.
        
    - Less scalable when dealing with thousands of concurrent requests.
        
    - Example: **RestClient**, **RestTemplate**.
        
- **Non-Blocking (Asynchronous / Reactive)**
    
    - The request is sent, and the thread is **released** to handle other work.
        
    - The response is processed later via callbacks or reactive streams.
        
    - Scales better with many concurrent calls.
        
    - Example: **WebClient** (Spring WebFlux).

## Building RestClient

```java
RestClient restClient = RestClient.builder()
    .baseUrl(BASE_URL)
    .defaultHeader(HttpHeaders.AUTHORIZATION,
        encodeBasic(properties.getUsername(), properties.getPassword()))
    .build();
```

---

## Configuration

```java
@Configuration
public class RestClientConfiguration {

    @Value("${employeeService.base.url}")
    private String BASE_URL;

    @Bean
    @Qualifier("employeeRestClient") 
    public RestClient getEmployeeServiceRestClient() {
        return RestClient.builder()
            .baseUrl(BASE_URL)
            .defaultHeader(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON_VALUE)
            .build();
    }
}
```

- `@Qualifier` → provides a unique identifier for this bean.
    
- Can define multiple `RestClient` beans for different services.

## Interface and Implementation

```java
public interface EmployeeClient {
    List<EmployeeDTO> getAllEmployee();
}
```

```java
@RequiredArgsConstructor
public class EmployeeClientImpl implements EmployeeClient {

    private final RestClient restClient;

    @Override
    public List<EmployeeDTO> getAllEmployee() {
        return restClient.get()
            .uri("employee/{employeeId}", 123) // appends to baseUrl
            .retrieve()
            .body(new ParameterizedTypeReference<List<EmployeeDTO>>() {});
    }
}
```

- `ParameterizedTypeReference<T>` is used to handle **generic type responses** like `List<EmployeeDTO>`.

## Example Usage

```java
CustomerResponse customer = restClient.get()
    .uri("/{id}", 3)
    .accept(MediaType.APPLICATION_JSON)
    .retrieve()
    .body(CustomerResponse.class);
```

Other supported methods:

- `.post()`
    
- `.put()`
    
- `.patch()`
    
- `.delete()`

## Error Handling

### Inline Error Handling

```java
ResponseEntity<Void> response = restClient.delete()
    .uri("/employee/{id}", 5)
    .retrieve()
    .onStatus(HttpStatusCode::is4xxClientError,
        (req, res) -> logger.error("Couldn't delete: " + res.getStatusText()))
    .toBodilessEntity();
```

### Global Error Handling (Configuration)

```java
@Configuration
public class RestClientConfiguration {

    @Value("${employeeService.base.url}")
    private String BASE_URL;

    @Bean
    @Qualifier("employeeRestClient")
    public RestClient getEmployeeServiceRestClient() {
        return RestClient.builder()
            .baseUrl(BASE_URL)
            .defaultHeader(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON_VALUE)
            .defaultStatusHandler(
                HttpStatusCode::is5xxServerError,
                (req, res) -> { throw new ResourceNotFoundException("Server Error: " + res.getStatusText()); }
            )
            .build();
    }
}
```

## Comparison with Other Clients

- **RestTemplate** (Old, blocking, will be deprecated in the future).
    
- **WebClient** (Reactive, non-blocking, part of Spring WebFlux).
    
- **RestClient** (Blocking, modern replacement for RestTemplate, simpler API).
