# Mapping - 2

## Many-to-One & One-to-Many

### `EmployeeEntity.java`

```java
package com.organization.jpaTuorial.jpatuts.entities;

import com.fasterxml.jackson.annotation.JsonIgnore;
import jakarta.persistence.*;
import lombok.*;

import java.util.Objects;

@Getter
@Setter
// @Data is not used because Lombok causes issues with equals() and hashCode().
// We create them manually.
@AllArgsConstructor
@NoArgsConstructor
@Entity
@Table(name = "employee")
public class EmployeeEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String name;

    // Doesn't create a new column in the database. Managed by DepartmentEntity.
    @OneToOne(mappedBy = "manager", cascade = CascadeType.ALL)
    @JsonIgnore
    private DepartmentEntity managedDepartment;

    @ManyToOne
    @JoinColumn(name = "worker_department_id", referencedColumnName = "id")
    @JsonIgnore
    private DepartmentEntity workerDepartment;

    @Override
    public boolean equals(Object o) {
        if (o == null || getClass() != o.getClass()) return false;
        EmployeeEntity that = (EmployeeEntity) o;
        return Objects.equals(id, that.id) && Objects.equals(name, that.name);
    }

    @Override
    public int hashCode() {
        return Objects.hash(id, name);
    }
}
```

### `DepartmentEntity.java`

```java
package com.organization.jpaTuorial.jpatuts.entities;

import jakarta.persistence.*;
import lombok.*;

import java.util.Objects;
import java.util.Set;

@Getter
@Setter
// @Data is not used because Lombok causes issues with equals() and hashCode().
@AllArgsConstructor
@NoArgsConstructor
@Entity
@Table(name = "department")
public class DepartmentEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String title;

    // One-to-One with Employee
    @OneToOne
    private EmployeeEntity manager;

    // One-to-Many with Employee
    @OneToMany(mappedBy = "workerDepartment")
    private Set<EmployeeEntity> workers;

    @Override
    public boolean equals(Object o) {
        if (o == null || getClass() != o.getClass()) return false;
        DepartmentEntity that = (DepartmentEntity) o;
        return Objects.equals(id, that.id) && Objects.equals(title, that.title);
    }

    @Override
    public int hashCode() {
        return Objects.hash(id, title);
    }
}
```

## Cascade

**Cascade**: Used to propagate operations from parent to child entities.

- `CascadeType.ALL` → Propagates all operations (`persist`, `merge`, `remove`, `refresh`, `detach`).
    
- `CascadeType.PERSIST` → Propagates `persist` (save).
    
- `CascadeType.MERGE` → Propagates `merge` (update).
    
- `CascadeType.REMOVE` → Propagates `remove` (delete).
    
- `CascadeType.REFRESH` → Refreshes child when parent is refreshed.
    
- `CascadeType.DETACH` → Detaches child when parent is detached.
    

---

## ⚡ Extra Crucial Points

- **Owning side**: The side that contains `@JoinColumn` is the _owning side_.
    
- **Inverse side**: The side that uses `mappedBy` is the _inverse side_.
    
- **Bidirectional relationships** must have one owning and one inverse side.
    
- Always implement **`equals()` and `hashCode()`** carefully for entities to avoid issues in collections.
