# Spring Data JPA & Dynamic Query Methods

## Spring Data JPA

- Part of the larger **Spring Data** family.
    
- Builds on top of **JPA**, providing a higher-level and more convenient abstraction for data access.
    
- Makes it easier to implement JPA-based repositories by providing:
    
    - Boilerplate code reduction
        
    - Custom query methods
        
    - Utilities for common tasks
        

![[spring-data-jpa-repository.png|center]]

---

### Key Features of Spring Data JPA

1. **Repository Abstraction** → Provides repository interfaces with methods for common data operations.
    
2. **Custom Query Methods** → Allows defining queries just by declaring method names.
    
3. **Pagination & Sorting** → Built-in support for `Pageable` and `Sort`.
    
4. **Query Derivation** → Automatically generates queries from method names.
    

```java
package com.organization.jpaTutorial.jpatuts.repository;

import com.organization.jpaTutorial.jpatuts.entities.Product;
import org.springframework.data.jpa.repository.JpaRepository;

import java.util.List;

public interface ProductRepository extends JpaRepository<Product, Long> {
    List<Product> findByTitle(String title);
}
```

> Spring Data JPA **automatically creates queries** without requiring concrete implementation.  
> ⚠️ Errors may occur if method names are not properly defined.

---

### Rules for Creating Method Names

```java
List<Product> findByDateCreatedBetween(LocalDateTime startDate, LocalDateTime endDate);
```

- **Return type** → `List<Product>`
    
- **Prefix** → `findBy`
    
- **Predicate** → `DateCreated`
    
- **Parameters** → `(LocalDateTime startDate, LocalDateTime endDate)`
    

#### Naming Rules

1. Query must start with **prefixes**:
    
    - `find...By`, `read...By`, `query...By`, `get...By`
        
    - Example: `findByName`, `readByName`, `queryByName`, `getByName`
        
2. To **limit results**, add `First` or `Top` before `By`:
    
    - Example: `findFirstByName`, `findFirst2ByName`, `findTop10ByName`
        
3. To **get unique results**, add `Distinct` before `By`:
    
    - Example: `findDistinctByName`, `findNameDistinctBy`
        
4. Use **logical operators**:
    
    - Example: `findByNameOrDescription`, `findByNameAndDescription`
        
5. Official Docs:  
    [Spring Data JPA Query Keywords Reference](https://docs.spring.io/spring-data/jpa/reference/repositories/query-keywords-reference.html)
    

> **Drawback:** Query derivation is limited — cannot handle **very complex queries**.

### Creating Custom Queries

For more complex conditions, use `@Query` annotation.

```java
// Use entity field names, not column names
// ?1 and ?2 → positional parameters
// :title and :price → named parameters

@Query("SELECT p FROM Product p WHERE p.title = ?1 AND p.price = ?2")
Optional<Product> findByTitleAndPrice(String title, BigDecimal price);
```

- Supports **JPQL**, **native queries** (`nativeQuery = true`), and **named parameters**.
    
- Useful when query derivation cannot handle the logic.
