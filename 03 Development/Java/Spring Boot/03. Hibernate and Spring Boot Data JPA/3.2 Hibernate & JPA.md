# Hibernate & JPA

## Hibernate ORM Mapping

Hibernate is a powerful, high-performance **Object Relational Mapping (ORM)** framework in Java.  
It allows mapping **object-oriented domain models** to **relational databases**.

- Hibernate implements the **JPA specification**.
    
- JPA is a standard, Hibernate is one implementation (others include EclipseLink, OpenJPA).

## JPA (Java Persistence API)

- **JPA** is a _specification_ (guideline for ORM in Java).
    
- Provides **annotations & interfaces** for mapping Java objects ↔ DB tables.
    
- It does **not** provide implementation.
    
- ORM frameworks like **Hibernate**, **EclipseLink**, **OpenJPA** implement JPA.
    

 With JPA, you can switch providers (e.g., Hibernate → EclipseLink) without rewriting code.

## Hibernate vs JPA

|Feature|JPA|Hibernate|
|---|---|---|
|Nature|Specification (API)|Implementation (framework)|
|Provides|Interfaces, Annotations|Actual ORM engine|
|Query|JPQL|JPQL + Native SQL + Criteria API|
|Portability|Portable across providers|Hibernate-specific|
|Extra Features|None (just standard)|Caching, batch processing, lazy loading, interceptors|

## JPA Key Annotations

- **@Entity** → Marks a class as an entity (table mapping).
    
- **@Table** → Customize table name, schema, indexes, constraints.
    
- **@Id** → Primary key field.
    
- **@GeneratedValue(strategy = GenerationType.IDENTITY)** → Auto PK generation.
    
- **@Column(name="name", nullable=false, length=50)** → Custom column mapping.
    
- **@CreationTimestamp, @UpdateTimestamp** → Auto timestamp fields.
    

Example:

```java
@Entity
@Table(
    name = "employees",
    uniqueConstraints = @UniqueConstraint(columnNames = {"email"}),
    indexes = {
        @Index(name = "idx_name", columnList = "name"),
        @Index(name = "idx_department", columnList = "department")
    }
)
public class Employee {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable=false, length=50)
    private String name;

    @Column(unique=true)
    private String email;
}
```

## Key Features of JPA

1. **Entity Management** → Mapping Java classes to DB tables.
    
2. **Query Language (JPQL)** → Object-oriented queries.
    
3. **Transaction Support** → Easier handling of DB operations.
    
4. **Entity Relationships** → OneToOne, OneToMany, ManyToOne, ManyToMany.
    
5. **Caching & Lazy Loading (Hibernate-specific)** → Performance optimizations.

- _JPA = Specification (what to do)_
    
- _Hibernate = Implementation (how it’s done)_
