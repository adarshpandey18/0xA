
# Mappings

## Core Concepts
- **Entity** → Class mapped to DB table
- **Primary Key** → Unique row identifier
- **Foreign Key** → Links two tables
- **Cascade** → Propagate operations
- **Fetch Type** → Eager vs Lazy loading

---

## Relationship Annotations
- `@OneToOne` → Example: Employee ↔ Department
- `@OneToMany` → Example: Department ↔ Employees
- `@ManyToOne` → Example: Employees ↔ Department
- `@ManyToMany` → Example: Students ↔ Courses

---

## 📝 Example: @OneToOne
### Entity Classes
```java
@Entity
@Table(name = "employee")
public class EmployeeEntity {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String name;

    @OneToOne(mappedBy = "manager") // inverse side
    private DepartmentEntity managedDepartment;
}
````

```java
@Entity
@Table(name = "department")
public class DepartmentEntity {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String title;

    @OneToOne
    @JoinColumn(name = "manager_id") // owning side
    private EmployeeEntity manager;
}
```

### Service Layer (Assign Manager)

```java
public DepartmentEntity assignManager(Long deptId, Long empId) {
    DepartmentEntity dept = departmentRepo.findById(deptId).orElseThrow();
    EmployeeEntity emp = employeeRepo.findById(empId).orElseThrow();
    dept.setManager(emp);
    return departmentRepo.save(dept);
}
```

### Controller

```java
@PutMapping("/{deptId}/manager/{empId}")
public DepartmentEntity assignManager(@PathVariable Long deptId, @PathVariable Long empId) {
    return departmentService.assignManager(deptId, empId);
}
```

---

## ⚡ Key Takeaways

- Always decide the **owning side** (`@JoinColumn`) vs **inverse side** (`mappedBy`).
    
- Use `@JsonIgnore` in bidirectional relationships to avoid infinite recursion in JSON.
    
- Choose **FetchType.LAZY** unless you really need eager loading.
