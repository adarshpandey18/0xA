# Installing MySQL & DBeaver

## Mysql
## Mac
1. Install homebrew on Mac
2. Install mysql using these commands:
	1. brew install mysql
	2. brew services start mysql
	3. mysql_secure_installation
	4. mysql -u root -p
## Windows
1. Use the Installer on Windows : [link](https://downloads.mysql.com/archives/installer)
2. Follow : [link](https://www.dataset.io/blog/install-mysql-windows/)
