# Sorting & Pagination

## Sorting with Method Queries

### Using `Order By`

```java
List<Product> findByTitleOrderByPrice(String title);
```

```java
@GetMapping  
public List<Product> getAllProducts() {  
    return productRepository.findByTitleOrderByPrice("Tablet Pro");  
}
```

>  Downside: With `OrderBy` we are tightly coupled to a particular field.

---

### Using `Sort` Parameter in Query Methods

```java
@Repository
public interface EmployeeRepository extends JpaRepository<Employee, Long> {
    List<Employee> findByDepartment(String department, Sort sort);
}
```

**Sort Class**

```java
Sort sort = Sort.by(Sort.Direction.ASC, "name");
Sort sort = Sort.by(Sort.Order.asc("name"), Sort.Order.desc("salary"));
```

```java
List<Product> findBy(Sort sort);
```

```java
@GetMapping  
public List<Product> getAllProducts(@RequestParam(defaultValue = "id") String sortBy) {  
    // If multiple products have same "sortBy", it will check "price", then "quantity"
    return productRepository.findBy(
        Sort.by(Sort.Direction.DESC, sortBy, "price", "quantity")
    );  
}
```

## Pagination

### Key Concepts

- **Page** → A single chunk of data that contains a subset of the dataset.
    
- **Pageable** → An interface that provides pagination info (page number, size, sorting).
    
- **PageRequest** → A concrete implementation of `Pageable`.
    

> Page index starts at **0**.

---

### Using Pageable

```java
public interface UserRepository extends JpaRepository<User, Long> {
    Page<User> findAll(Pageable pageable);
    Page<User> findByLastName(String lastName, Pageable pageable);
}
```

### Creating Pageable Instance

```java
Pageable pageable = PageRequest.of(pageNumber, size, Sort.by("lastName").ascending());
```

---

### Example: Product Repository

```java
@Repository  
public interface ProductRepository extends JpaRepository<Product, Long> {  
    Page<Product> findAll(Pageable pageable);  
}
```

---

### Example: Controller

```java
@RestController  
@RequestMapping(path = "/products")  
public class ProductController {  

    private static final int PAGE_SIZE = 3;  
    private final ProductRepository productRepository;  

    public ProductController(ProductRepository productRepository) {  
        this.productRepository = productRepository;  
    }  

    @GetMapping  
    public Page<Product> getAllProducts(@RequestParam(defaultValue = "id") String sortBy,  
                                        @RequestParam(defaultValue = "0") Integer pageNumber) {  
        Pageable pageable = PageRequest.of(pageNumber, PAGE_SIZE, Sort.by(sortBy));  
        return productRepository.findAll(pageable);  
    }  
}
```

## Extra Points to Remember

-  `Page<T>` gives metadata (total pages, total elements, etc.), while `List<T>` only gives data.
    
-  Use DTO projection with pagination to avoid fetching unnecessary fields.
    
-  For large datasets, consider **keyset pagination** (better performance than offset-based pagination).
