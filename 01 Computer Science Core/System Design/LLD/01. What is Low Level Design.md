# What is Low Level Design?

Low Level Design (LLD) is the process of breaking down high-level system designs into detailed, implementable components. It acts as a bridge between system design and actual coding, focusing on class structures, interactions, and logic flow.

**Definition**: Writing code in a way that not only solves current requirements but also remains adaptable for future needs.

---

## 3 Essentials to Identify Good Code

### 1. Readability  
Code should be easy to read and understand, even for someone new to the project.

### 2. Extensibility  
The design should allow changes in requirements to be implemented with minimal modifications.

### 3. Correctness  
The code must be reliable and function as intended. Since the cost of fixing bugs increases over time, correctness at the design stage is critical.
