# What is Low Level Design ?


Low level design is mixture of designing & coding.
Definition : coding across time 

when writing code we need to pay attention to satisfy not only current requiremenet but for future too.

## 3 essentials for knowing code is good or bad

### 1. Readable
### 2. Extensibility - if requirements change without doing much changes we should be able to implement it without much effort.
### 3. Correctness - the cost to fix bugs is very high. It should be reliable
